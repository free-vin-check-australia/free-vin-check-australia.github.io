VIN vs Rego Number – What Is the Difference?

A VIN identifies the vehicle. A rego number identifies its current registration. They are used for different checks in Australia.

Last updated 24 November 2026

VIN vs registration number

IdentifierWhat it identifiesWhere it is used
VINA specific vehicle, usually a 17-character identifier on modern vehicles.Vehicle identification, manufacturer data, PPSR and some registration lookups.
Rego / number plateA registration issued by a state or territory. It can change when plates or registration change.State and territory registration status and expiry lookups.

Can you use a rego number for a PPSR check?

No. The official PPSR vehicle search requires the vehicle’s VIN or chassis number. It does not allow a search by registration plate or engine number. Use the relevant state or territory rego service to look up registration information, then obtain and verify the VIN before a PPSR search.

Why both checks matter

A vehicle can have current registration while still having a security interest recorded. A VIN can be correctly formatted while the vehicle has a theft, write-off or other history issue. Registration, VIN validation and PPSR are separate checks and should be treated separately.

Recommended steps

  1. Check the state or territory registration using the number plate.
  2. Compare the physical VIN with the VIN on the paperwork.
  3. Run the official PPSR search using that VIN or chassis number.
  4. Check recalls and request service records; arrange an independent inspection.
